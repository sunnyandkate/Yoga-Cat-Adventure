#  Yoga Cat Adventure (Unity / C#)

A cozy, relaxed 2D exploration game. Players take control of a charming cat navigating a relaxed, top-down environment to complete quests and interactive loops.

## Play the Build
You can play the live, fully compiled build of the game directly in your browser on itch.io: 
 **[ https://sunnyandkate.itch.io/yogacatadventure ]**

##  Key Implementation Highlights
* **Core Player Controller:** Scripted fluid 2D movement physics and interactive collision frameworks in C# tailored for relaxed exploration mechanics.
* **UI & Menu States:** Built intuitive, responsive screen layouts and menu structures inside Unity to guarantee a seamless user onboarding flow.
* **Custom 2D Visuals:** Hand-designed and animated all 2D pixel art sprites, environmental tilemaps and asset sheets using Aseprite to establish a polished visual hierarchy.

##  Repository Structure
* `/Assets/Scripts` — Contains all custom C# scripts handling movement, player logic and interactive mechanics.
* `/Assets/Scenes` — Holds the main gameplay layout configurations and screen states.
